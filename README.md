# You&Me — приложение на двоих

Личный веб-аналог приложения You&Me: главная **«Мы»** (дни вместе, годовщины, итоги года), **общий календарь**, **люди и дни рождения**, **хотелки** с тайной бронью подарка, **планы** с общим бюджетом, **задачи** со «свободными», **покупки**, **вопрос дня**, **капсулы времени** и **карты лояльности**. Ставится на экран «Домой» iPhone как обычное приложение и работает офлайн.

- **Хостинг** — бесплатный GitHub Pages (этот репозиторий, он публичный — в нём только код).
- **База данных** — ваш **второй, приватный** репозиторий на GitHub (JSON-файлы + фото).
- **Пуш-уведомления** — бесплатные GitHub Actions в приватном репо.
- **Подтяжка хотелок по ссылке** — необязательный бесплатный Cloudflare Worker.

Посмотреть без настройки: `https://ermin372.github.io/You-me/?demo` (после первого деплоя).

## Что умеет

Вкладки: **Мы · Календарь · Хотелки (+ Планы) · Дела (Задачи + Покупки) · Карты**. Вопрос дня и капсулы открываются с «Мы».

| Раздел | Что есть |
|---|---|
| Мы | «1 250 дней вместе», «211 дней до четвёртой годовщины», «Наш 2026-й» (хотелки исполнено, поездки, закрытые планы, фото + подробности по годам), карточка вопроса дня, «Скоро», письма |
| Календарь | Месяц с понедельника, точки событий цветом того, кто добавил, полосы многодневных поездок, «Ближайшие», годовщины со счётчиком лет, повтор каждый год, свайп по месяцам |
| Люди | Дни рождения родных/друзей, возраст, «чей человек», идеи подарков — сами попадают в календарь |
| Хотелки | Ссылка, цена в любой валюте, фото, «очень хочу», фильтр по человеку, **тайная бронь «Я подарю»** (владелец не видит), архив «Подарено» |
| Планы | Бюджет в своей валюте, траты и «отложили» каждого, перерасход (+34 300 ₽), **«чтобы вышло поровну: кто → кому»** |
| Вопрос дня | 445 вопросов в 10 темах, одинаковый вопрос обоим, ответ партнёра открывается только после твоего, архив, ответы задним числом, серия дней 🔥 |
| Задачи | Все / Мои / партнёра / Свободные; «Беру» одним касанием; в работе, свободные, готово; сроки и просрочка |
| Покупки | Общий чек-лист, несколько позиций через запятую, кто добавил / кто купил |
| Капсулы | Письма в будущее: кому (партнёру или обоим), дата открытия и пресеты (годовщина, 14 февраля, Новый год…), фото; до даты адресат видит только «Тебя ждёт письмо от…»; «прочитано обоими» |
| Тема | Светлая и тёмная по системе iPhone или вручную (Настройки → Тема) |
| Карты | EAN-13, EAN-8, UPC, Code 128, Code 39, ITF, QR; сканер камерой или из фото; штрихкод на белом экране, экран не гаснет |
| Офлайн | Всё кэшируется на телефоне, правки без сети уходят в очередь и отправляются при появлении связи |
| Уведомления | Партнёр добавил хотелку/событие/покупку/трату/задачу/письмо, взял или сделал задачу, ответил на вопрос; утром — ДР, события, сроки задач, открывшиеся письма, годовщина и каждые 100 дней вместе; вечером — напоминание про вопрос |

## Установка (≈15 минут, один раз)

### 1. Включи GitHub Pages для этого репо

1. `ERMIN372/You-me` → **Settings → Pages** → *Build and deployment* → **Source: GitHub Actions**.
2. Смёрджи PR в `main` — workflow `Deploy to GitHub Pages` соберёт и выложит сайт.
3. Адрес: **https://ermin372.github.io/You-me/**

### 2. Создай приватный репозиторий для данных

GitHub → **New repository** → имя, например, `you-me-data` → **Private** → ✅ *Add a README file* → Create.

### 3. Создай токен доступа (fine-grained PAT, Personal Access Token)

GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:

- **Repository access**: *Only select repositories* → `you-me-data` (только он!).
- **Permissions → Repository permissions**:
  - **Contents: Read and write** — чтение/запись данных (обязательно);
  - **Workflows: Read and write** — чтобы приложение само поставило автоматизацию уведомлений (можно не давать и скопировать файлы из `data-repo/` руками);
  - *Metadata: Read* добавится сам.
- **Expiration** — поставь максимальный срок и запиши, когда продлевать. Когда токен истечёт, приложение покажет «Токен не работает» — создай новый и переподключись.

### 4. Установи на свой iPhone

1. Открой адрес из шага 1 в **Safari** → **Поделиться → На экран «Домой»**.
2. Запусти **с экрана «Домой»** (важно: у ярлыка своё хранилище, из Safari настройки не переносятся).
3. «Первый запуск» → `ERMIN372/you-me-data` + токен → «Подключиться».
4. Впиши имена, как склонять («добавил/добавила») и цвета.

### 5. Подключи телефон девушки

1. На её iPhone: Safari → адрес → **На экран «Домой»** → открыть ярлык.
2. На твоём: **Настройки** (два кружка вверху) → **Подключить второй телефон** → QR-код.
3. На её: **«У меня есть код» → «Сканировать QR»** → выбрать себя.

> В QR — токен. Показывай с экрана, не пересылай в мессенджеры.

### 6. Уведомления (по желанию)

Нужно iOS 16.4+ и запуск с экрана «Домой».

1. На любом телефоне: **Настройки → Уведомления → «Настроить уведомления»** (один раз). Приложение сгенерирует ключи VAPID (ключи для подписи пушей) и положит в `you-me-data` workflow `.github/workflows/you-me-notify.yml`.
2. На **каждом** телефоне: **«На этом устройстве» → включить** → разрешить.
3. «Прислать тестовое» — придёт через ~30–60 секунд (столько стартует GitHub Actions).

Расписание: утром в 09:00 МСК — ДР и события дня/завтра, за неделю до ДР — напоминание про подарок; в 20:00 МСК — тем, кто не ответил на вопрос дня. Время меняется в `cron` внутри `you-me-notify.yml` (время в UTC). GitHub может запускать cron с опозданием до ~часа — это нормально.

**Лимиты.** Для приватных репо на бесплатном плане GitHub даёт 2000 минут Actions в месяц; каждое уведомление ≈ 1 минута (округление вверх). 2 расписания в день = ~60 мин/мес, остаётся ~1900 уведомлений. Покупки, добавленные подряд, склеиваются в одно уведомление.

### 7. Хотелки по ссылке (по желанию)

Браузер не может читать чужие сайты (CORS, защита браузера от междоменных запросов), поэтому нужен маленький прокси. Инструкция — [`worker/README.md`](worker/README.md). После деплоя: **Настройки → Хотелки по ссылке** → адрес Worker + ключ. В форме хотелки появится кнопка «Подтянуть».

## Как это устроено

```
iPhone (PWA, офлайн-кэш, IndexedDB)
   │  GitHub REST API + ваш токен
   ▼
ERMIN372/you-me-data (private)
   ├─ data/events.json, wishes.json, plans.json, answers.json … — по строке на запись
   ├─ img/2026-09/…jpg — сжатые фото хотелок (~150 КБ)
   └─ .github/workflows/you-me-notify.yml → Web Push на ваши телефоны
```

- **Синхронизация**: раз в 20 секунд, пока приложение открыто, + при открытии и после каждой правки. Проверка «что-то изменилось?» — один условный запрос с ETag (метка версии; ответ 304 не тратит лимит GitHub).
- **Конфликты**: если вы правите одновременно, записи сливаются по отдельности — у каждой своя метка времени, побеждает последняя правка. Одновременно добавленные покупки/события не теряются (покрыто тестами).
- **Удаление** хранится как «надгробие» 180 дней, чтобы старый офлайн-телефон не воскресил запись.

## Честно про ограничения

- **«Подсмотреть не выйдет» — только на уровне интерфейса.** Ответы на вопрос дня и тайные брони лежат в приватном репо открытым текстом: у кого есть токен, тот технически может открыть `data/answers.json` на GitHub. Для пары на доверии — ок; вы выбрали этот вариант.
- **Капсулы** закрыты тоже только в интерфейсе: текст письма лежит в `data/capsules.json` открытым текстом.
- **Виджетов на домашнем экране не будет**: iOS не даёт веб-приложениям (PWA) делать виджеты — это умеют только нативные приложения.
- **Цвет полосы статуса** в светлой теме: используется стиль `default` + `theme-color`. На iOS 15+ полоса должна перекрашиваться под тему, но на реальном iPhone я это не проверял — если полоса выглядит странно, напиши.
- **Склонение имён** («письмо от Софьи») угадывается автоматически; если ошиблось — Настройки → профиль → «От кого?».
- **Яркость** на карте лояльности веб-приложение менять не может (у iOS нет такого API) — прибавь вручную. Зато экран не гаснет (Screen Wake Lock).
- **Токен** лежит в хранилище телефона. Он даёт доступ только к `you-me-data` — поэтому важно ограничить его одним репо.
- **Реального «онлайна» нет**: правка партнёра появится у тебя в течение ~20 секунд, пока приложение открыто.
- **VAPID-ключ** (подпись пушей) хранится в `data/config.json` приватного репо — так не нужно вручную заводить секреты. Если хочешь строже: добавь секрет `VAPID_PRIVATE_KEY` в репо данных, workflow возьмёт его первым.
- **Ozon / Wildberries** часто блокируют автоматические запросы — тогда «Подтянуть» ничего не найдёт, заполни руками.
- **Фото** при удалении хотелки остаются в репо (место почти не занимают).

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173/?demo — демо без GitHub
npm test           # vitest: синхронизация, конфликты, даты, бюджеты, штрихкоды, вопросы
npm run build      # сборка в dist/
npm run icons      # перегенерировать PNG-иконки (нужен Playwright)
```

Стек: Vite + Preact + TypeScript, vite-plugin-pwa (Workbox), idb-keyval, JsBarcode, qrcode-generator, ZXing.

Вопросы для «Вопроса дня» — в `src/data/questions.ts`, по одному на строку; можно дописывать свои.

Шаблоны для репо данных — `data-repo/`, код Worker — `worker/`.
